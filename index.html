IDENTIDADE E ENGENHARIA

Base Demo Oficial - SI

Uma infraestrutura independente, destinada a receber diferentes simuladores educativos.

Princípios do projeto

Universalidade: o núcleo não contém regras de uma disciplina científica.

Autonomia: nenhuma conexão é exigida para executar a aplicação.

Camadas: implementação progressiva, com contratos e critérios de aceite a cada fase.

Evolução: a plataforma será ampliada gradualmente, com testes de compatibilidade e comportamento antes de cada homologação.

Versão da plataforma: 0.6.0.
