Conferência antes da publicação

A criação é local. Após salvar, abra a biblioteca para gerar o link ou exportar o JSON.

Biblioteca do professor

O link contém uma cópia da atividade. Não envia dados a nenhum servidor. Um endereço gerado em arquivo local (`file://`) só funciona no mesmo caminho/dispositivo; para outras pessoas, use um endereço web compartilhado.

A importação substitui somente as atividades personalizadas após confirmação. Dados incompatíveis são rejeitados antes da gravação.

IDENTIDADE E ENGENHARIA

Base Demo Oficial - SI

Uma infraestrutura independente, destinada a receber diferentes simuladores educativos.

Princípios do projeto

Universalidade: o núcleo não contém regras de uma disciplina científica.

Autonomia: nenhuma conexão é exigida para executar a aplicação.

Camadas: implementação progressiva, com contratos e critérios de aceite a cada fase.

Evolução: a plataforma será ampliada gradualmente, com testes de compatibilidade e comportamento antes de cada homologação.

Versão da plataforma: 0.9.6.
